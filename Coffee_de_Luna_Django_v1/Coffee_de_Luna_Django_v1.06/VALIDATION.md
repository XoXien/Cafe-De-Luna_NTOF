# Validation · Coffee de Luna v1.06

- **115 Django tests passed** on Django 5.2.19: all 93 existing tests (updated for the nested add-on API) and 22 new drink-customization and migration tests.
- Tests cover per-drink extras, quantity scaling, separate configurations, identical-configuration merging, exact menu charges, equal-volume oat swaps for hot and iced drinks, added oat portions for Americano, included cream/condensed milk, and stock availability with unavailable whole milk.
- Invalid add-on IDs, duplicate choices, flat add-on lines, drink IDs used as extras, malformed quantities, multiple syrup flavours, inactive options, and portion limits are rejected. Shared ingredient shortages roll back the order and all stock movements.
- Checkout idempotency, immutable cost/ingredient snapshots, exact cancellation returns after recipe changes, guest rendering, grouped receipts/tracking, and drink-only favourites are verified.
- Upgrade tests preserve existing balances, prices, edited recipes, stock-addition history, notes, accounts, and historical orders. No business data is created automatically by migrations.
- **43 DOM UI assertions passed** using actual rendered Django customer and counter pages. They cover size/flavour/topping selection, milk selection, espresso/syrup/cream pricing, per-drink totals, quantity changes, cart editing/cancel, separate configurations, saved-cart restoration, nested checkout payloads, stock-error recovery, search/category filtering, explicit paid milk selection when whole milk is unavailable, and counter payment/discount fields.
- Django system checks, migration consistency (`makemigrations --check --dry-run`), Python syntax, JavaScript syntax, and CSS parsing passed.
- All 60 source menu prices, variant labels, and base recipes remain unchanged. The 34 ingredient presets keep their opening quantities, costs, and storage classifications. Only the oat-milk note and option behavior metadata were updated.
- The archive is checked to exclude database files, accounts, customer orders, runtime media, local secrets, virtual environments, startup batch/shell scripts, and generated bytecode. Menu presets and the source/reference files are included for explicit import.

DOM tests validate interaction logic. They do not constitute a visual browser review; responsive desktop/mobile styles were implemented, but a rendered browser review was unavailable in this environment. The supplied menu establishes prices and sizes. Recipe quantities, milk substitution rules, portions, storage forms, stock levels, and costs are assumptions to confirm with the café; see MENU_ASSUMPTIONS.md.
